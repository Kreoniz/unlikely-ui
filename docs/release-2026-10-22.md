# Scroll Area alpha release

Published on 2026-10-22. npm accepted the upload and a subsequent registry
lookup confirmed `unlikely-ui@0.1.0-alpha.2` is available.

- Package: [unlikely-ui@0.1.0-alpha.2](https://www.npmjs.com/package/unlikely-ui/v/0.1.0-alpha.2).
- Public access, official npm registry, MIT code/documentation license.
- `next` points to alpha.2; `latest` remains alpha.1 from the first-publication
  exception. No stable release or tag promotion was performed.
- Source: `438cb30627863436f1a033ee09671e6cad97c95d`, tagged `v0.1.0-alpha.2`.
- Twenty-two preview components; existing APIs, peer ranges, and semantic token
  values remain unchanged.

## Changes

- ScrollArea: Base UI native scrolling, vertical/horizontal scrollbar styling,
  keyboard and thumb dragging, dynamic overflow, scoped themes, RTL, and
  forced-colors support. Root and `unlikely-ui/scroll-area` exports include types.
- Showcase navigation and code examples use ScrollArea.
- Toast content measurement no longer depends on the animated stack height.
- Package metadata and README link to the public repository and showcase.

## Release checks and publication

Frozen offline installation and formatting passed. `pnpm release:check` passed:
TypeScript, 6 API tests, 98 contrast pairs, the production showcase, 38 showcase
browser tests, and 12 packed-consumer browser tests across plain React and
Tailwind. Consumer checks also covered declarations, SSR/hydration, style
isolation, portal inheritance, export targets, and consumer document links.
ScrollArea screenshots were reviewed at narrow and wide widths in both themes.

The inspected tarball contained 87 allowed files, including ScrollArea runtime,
types, source map, and styles. No artwork, fonts, credentials, or local path
markers were found in the inspected package.

The ordinary directory publish completed its lifecycle checks and clean build,
then required publishing 2FA. The checked pnpm tarball was submitted interactively
with the owner's browser approval, avoiding another test run. npm briefly
processed the upload before the version became available. At the owner's
request, post-publication verification was limited to version availability and
distribution tags; no public-tarball audit was performed.

## Known limitation

The Combobox showcase scenario can emit intermittent ResizeObserver loop
notifications during async result changes, including with CI's Chromium version.
Its behavior tests pass. Dedicated ScrollArea and mixed-height Toast regression
cases reported no resize errors. These checks do not establish comprehensive
accessibility or framework compatibility.
