## Implementation details worth preserving

- The showcase reset belongs to the gallery, not the installed runtime. Do not
  repair integration problems by adding blanket important declarations.
- The Switch thumb uses logical inset positioning. The production CSS toolchain
  can lower `:dir(rtl)` into language selectors; that did not honor an explicit
  Theme direction in the first implementation. Browser checks inspect the built
  result and packed CSS, including actual RTL geometry.
- DatePicker itself remains a standalone selector. A hidden input supplies a
  submitted value; it does not implement required validation. The recipe handles
  validation and focus explicitly and avoids UTC conversion of local dates.
- API extraction remains TypeScript-driven. There are no handwritten prop
  tables, duplicate palette values, or edits to generated API data.
- Full schedules, data-table engines, a form-state framework, a source registry,
  determinate progress, and Combobox chip additions are outside this change.
  Existing multiple-selection capability inherited by Combobox.Root is unchanged.
