## Changes and upgrade impact

Alpha.3 adds Switch, Tabs and Menu, plus the `unlikely-ui/dropdown-menu` alias.
The shared implementation adopts shadcn Base UI named parts, callable roots,
standard Button variants, `buttonVariants`, composed Combobox controls and
scoped semantic Tailwind utilities. Compound compatibility surfaces remain;
matching names do not imply universal shadcn block compatibility or automatic
upstream synchronization.

**Audit Dialog upgrades:** DialogContent and Dialog.Content now include a
corner close action by default. Set `showCloseButton={false}` when preserving
custom dismissal controls or policies, then recheck tab order and focus return.
ComboboxInput is composed while Combobox.Input remains bare. Removable
ComboboxChip requires a localized value-specific removeLabel. Follow
[the consumer migration guidance](../USAGE.md#upgrades-and-validation).

Explicit Theme language reaches nested portals. The release also corrects
retained-dialog click interception, DatePicker disabling while open and RTL Tabs
selection styling. Installation guidance, API discovery and complete portable
recipes describe the matching release.

The showcase includes rebuilt Receipt, Split-flap, Guarded action, Allocation
bar, XY pad and Radial menu studies, plus app compositions. These remain
experiments outside the npm package. Owner acceptance and broader adoption
remain unproved.
