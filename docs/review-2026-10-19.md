# Library review — 2026-10-19

Three independent reviewers covered UI/UX and usability; API simplicity,
documentation and agent guidance; and skeptical review of the findings and
validation. Reviews used the current source, generated references, installed
Base UI declarations/runtime and the local showcase. The package is private;
Campus migration and publication were outside scope.

Status: all seven follow-up findings are resolved. The original findings below
are retained as review evidence; the resolution table records the final changes.

## Corrected in this change

Tooltip timing was the reported problem: after the first opening, Base UI's
Provider made subsequent hovers instant. Its Trigger bypasses configured delays
while the group is active, so setting the warmup timeout to zero alone would
not fix movement directly between triggers.

The library Provider now shares `delay` and `closeDelay` configuration without
creating a Base UI delay group. Base UI still owns hover timers, positioning,
keyboard behavior and dismissal. Every hover uses the chosen delay; keyboard
focus opens immediately. Trigger overrides take precedence, including zero.
Provider's `timeout` prop was removed because there is no instant-open phase.
This is a deliberate change to the private preview API.

The showcase includes two enabled triggers. Regression checks cover repeated
hover, movement directly between triggers at 300/600ms, instant hover and
immediate keyboard focus with 600ms selected. The packed consumer fixture also
checks inherited opening/closing delays and Trigger overrides.

## Agent guidance and simplicity

Root [AGENTS.md](../AGENTS.md) appropriately describes developing this library:
its stack, source boundaries, tokens, Base UI composition, publication limits
and meaningful validation. Keep it contributor focused.

For agents using the installed library, [USAGE.md](../USAGE.md) is now linked
from README and included in npm files with the component contracts. It covers:

- Subpath imports, one explicit stylesheet import and a Theme boundary.
- The tested Tailwind import/layer recipe; plain consumers need no Tailwind.
- Base UI `render` composition, accessible icon names and labeled controls.
- Content already supplying its portal; token overrides reaching nested portals.
- App-owned state, dates/time zones and appearance persistence.
- Exact preview version pinning and where to inspect emitted public types.

Contributor AGENTS.md remains separate and excluded from npm. No duplicate API
tables, documentation framework, registry, installer or new component was added.

## Skeptic checks

- Rejected `timeout={0}` as an incomplete fix for active trigger handoff.
- Distinguished intentional calendar scrolling from broken calendar semantics;
  shrinking touch targets is not an acceptable remedy.
- Distinguished Base UI's ref declaration from a proven library runtime bug.
- Tested the suspicion that the docs runner's single-file summary skipped named
  assertions. A deliberately failing temporary copy failed as expected, so this
  was rejected as a correctness finding.
- Caught a timing-test gap: keyboard focus must be checked with a nonzero delay,
  rather than only after selecting Instant. The final test uses 600ms.

These are targeted review findings, not a claim of exhaustive browser,
accessibility or framework compatibility coverage.
