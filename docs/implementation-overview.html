Distribution · different ownership models

Concern Npm · recommended first Source registry · optional later
Installed as Versioned dependency Editable local files + dependencies
Customization Tokens, variants, composition and documented overrides Component internals and markup
Shared fixes Upgrade the package Review and merge into local copies
Selection Subpath exports; verify unused JS is removed. Combined CSS initially. Requested items plus their shared files and dependencies
Delivery work Build, exports, release and consumer fixture Registry metadata, imports/styles setup and install fixture

Custom registries can use the existing shadcn registry protocol and CLI.

Later registry: same source → generated release items → verified installation. Existing npm consumers can keep their current adoption mode.
